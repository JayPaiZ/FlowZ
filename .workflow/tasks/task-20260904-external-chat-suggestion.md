# Goal

在不增加新 Skill、插件或浏览器自动化的前提下，让 Agent 在网页端可以
独立完成较大文字分析时，主动提供一个可选的用户介导辅助建议。

# Decisions

- v0.1 不纳入图片分析。
- 仅在任务不需要项目上下文、命令、文件修改或运行状态检查时建议。
- 长输入只是建议信号，不建立额外的分块、预检或强制任务包流程。
- Agent 提供简短提示词，用户自行决定是否使用。
- 返回结果只作为未验证参考，不与同目的 Skill 自动重复运行。
- 用户明确要求开启或关闭建议时，覆盖 Agent 的自动判断。
- 普通开发任务的哈希边界不变；本设计不涉及哈希。
