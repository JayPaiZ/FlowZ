# Goal

停止插件开发，将当前 Lite 内容提升为唯一主线，并以此基线建立私有 GitHub 仓库，后续继续开发各环境适配文档。

## Scope

### In scope

- 移除工作目录中旧主线的插件相关对话文件和旧项目文件，仅保留当前 Lite 内容。
- 将 `FlowZ_Lite` 内全部内容移动到项目根目录，并删除空的 `FlowZ_Lite` 目录。
- 初始化本地 Git 仓库，建立初始主线提交。
- 在已登录的 GitHub 账户下创建私有 `FlowZ` 仓库并推送当前基线。
- 记录后续先完成 Cline 适配、再创建备份分支并清理主线适配内容的版本策略。

### Out of scope

- 继续开发或维护插件。
- 创建、安装或修改 Skill。
- 现在创建后续 Cline 功能分支或删除已确认的 Cline 适配内容。
- 修改用户目录中的其他全局规则或其他项目文件。
