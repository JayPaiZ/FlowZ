# Goal

在不牺牲任务完成质量的前提下，减少重复上下文、无效输出和失败重试，
并将简单可观察的验证交给用户执行。

# Decisions

- Standard / Full 任务在阶段边界使用紧凑任务包，Quick 默认保持会话内。
- 关键目标、约束、决定、风险、验收条件和验证状态不得被压缩掉。
- 按任务风险选择节省强度；Full 任务不因效率规则跳过必要设计或复核。
- 失败后只传递增量证据；出现质量信号时恢复所需详细程度并升级任务等级。
- 用户可执行的低风险验证由 Agent 提供命令、操作路径和预期结果。
- 普通开发任务中 Agent 不计算、展示或索要哈希；哈希仅用于安装器或明确的完整性工具。
- 不在缺少证据时设置硬性 token 上限，也不宣称未经测量的节省或完成率改善。
